# Glossary

| Term | Meaning |
|---|---|
| **Authority** | An organisation trusted by sites to sign firmware or certify identities. |
| **Capability** | One thing a device can sense or do, described by the device itself. |
| **Device** | A field device or a gateway. |
| **Field device** | A sensor or actuator connected to a gateway. |
| **Gateway** | The device that connects field devices to the site network. |
| **Hub** | An optional service above one or several sites, chosen by the owner. |
| **Identity** | The permanent, unique identity of a device, given at manufacturing. |
| **Label** | The sticker on a device that shows its identity to people and scanners. |
| **Manufacturer** | An organisation that produces Ghost devices in its workshops. |
| **Readable code** | The short code with a check letter that people use to recognise a device. |
| **Record** | What a manufacturer keeps about a device it produced. |
| **Site** | One installation (for example a car park) with its own network and site server. |
| **Site server** | The system that runs a site: devices, history, alarms and screens. |
| **Workshop** | The place where devices are flashed, identified and labelled. |
